# 프로젝트와 카테고리

## 계층

```
프로젝트 (가장 큰 단위)
 └── 카테고리   작업일지 / 코드 스니펫 / 일반 노트
      └── 문서
```

- **프로젝트**는 실제 DB 테이블(`Project`)이다. 이름은 중복될 수 없다.
- **카테고리**는 `Note.kind` 열거형이다. 별도 테이블이 없으므로 프로젝트를 만들면
  세 카테고리가 **자동으로 딸려온다** — 비어 있어도 사이드바에 항상 표시된다.
- **미분류**(`projectId = null`)가 기본값이다. 프로젝트를 지정하지 않은 문서가 여기 모인다.
  실제 행이 아니라 "프로젝트 없음" 상태이므로 지울 수 없고 항상 존재한다.

## 프로젝트 = 공유 단위

프로젝트는 계층 구조인 동시에 **누가 무엇을 보는지를 가르는 경계**이기도 하다.

- **미분류는 만든 사람만 본다.** 다른 계정에게는 존재조차 보이지 않는다
- **프로젝트에 배정된 문서는 그 프로젝트 멤버 전원이 본다.** 자세한 멤버 관리(초대/제거/
  소유자 승격)는 [accounts.md](accounts.md)
- **비밀번호도 같은 규칙이다** - 미분류는 만든 사람만, 프로젝트에 넣으면 멤버 전원이 본다.
  값이 어떻게 보관되는지는 [security.md](security.md)

## 프로젝트를 지우면

**안의 문서는 지워지지 않는다.** 외래키가 `ON DELETE SET NULL`이라 노트와 비밀번호가
미분류로 이동할 뿐이다. 삭제 확인 창이 몇 건이 이동하는지 미리 알려준다.

보관(archive)은 삭제와 다르다. 사이드바에서 감추기만 하고 내용은 그대로 둔다.

## 비밀번호도 프로젝트에 묶인다

`Secret.projectId`가 있어서 "이 프로젝트의 서버 비밀번호"처럼 묶어둘 수 있고, 묶는 순간
그 프로젝트 멤버 전원이 함께 쓴다. 나중에 다른 프로젝트로 옮기거나 미분류로 빼는 것도 된다.

## URL

| 화면 | URL |
|---|---|
| 전체 노트 (프로젝트 가로지르기) | `/notes` |
| 프로젝트 전체 | `/notes?project=<id>` |
| 프로젝트 안의 카테고리 | `/notes?project=<id>&kind=WORKLOG` |
| 미분류 | `/notes?project=none` |
| 프로젝트 관리 | `/projects` |

## 문서 생성

카테고리 화면의 **"새 {카테고리}"** 버튼으로 만들면 프로젝트와 카테고리가 자동으로 붙는다.
프로젝트 전체 화면에서는 카테고리별 버튼 세 개가 나온다.
에디터 상단의 `프로젝트 / 카테고리` 선택으로 나중에 옮길 수도 있다.

## 수정

프로젝트 관리 화면(`/projects`)의 **수정** 버튼으로 이름·설명·색상·저장소 주소를 바꾼다.
이름을 다른 프로젝트와 겹치게 바꾸면 409로 거부된다.

비밀번호 항목도 목록에서 **수정**할 수 있다. 비밀번호 칸을 비워두면 기존 값이 그대로 유지되며,
값을 새로 입력한 경우에만 교체한다.

## API

| 요청 | 하는 일 |
|---|---|
| `GET /api/projects` | 목록. 프로젝트별·카테고리별 개수 포함 |
| `POST /api/projects` | 생성. 이름 중복 시 409 |
| `PATCH /api/projects/:id` | 이름·설명·색상·저장소·보관 여부 변경. 이름 중복 시 409 |
| `DELETE /api/projects/:id` | 삭제. 내용은 미분류로 이동 |
| `GET /api/notes?project=<id\|이름\|none>` | 프로젝트로 필터. `kind`와 조합 가능 |

`project` 파라미터는 **ID와 이름을 모두** 받는다. MCP 쪽에서 이름만 아는 경우가 많기 때문이다.

## MCP

| 도구 | 프로젝트 관련 |
|---|---|
| `list_projects` | 프로젝트와 카테고리별 개수 조회 |
| `create_project` | 프로젝트 생성 |
| `create_note` | `project` 인자로 소속 지정 |
| `update_note` | 기존 노트를 다른 프로젝트/카테고리로 이동 |
| `search_notes` | `project` 인자로 범위 한정 |
| `list_secrets` | `project` 인자로 범위 한정 |

쓰는 법:

```
"ScvNote 프로젝트 작업일지에 오늘 한 거 정리해줘"
"NAS 프로젝트에서 도커 관련해서 적어둔 거 찾아줘"
"방금 그 노트 ScvNote 프로젝트로 옮겨줘"
```

## 코드 저장소 연결

프로젝트를 만들 때나 **수정**에서 저장소 주소(http/https)를 넣을 수 있다. 넣으면 목록에
`저장소` 링크가 보이고, **그 프로젝트의 작업일지는 MCP로 저장할 때 빌드 번호를 요구한다** —
어느 빌드의 작업인지 나중에 검색으로 되짚기 위해서다. 자세한 형식은 [mcp.md](mcp.md).

주소를 비워두면 그냥 일반 프로젝트다. 회의록처럼 코드와 무관한 일지는 셀 커밋이 없으므로
아무 제약 없이 저장된다.
